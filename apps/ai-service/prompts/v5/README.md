# Prompt Set v5

Version 5 retains the v4 routing, dependency, specialist, synthesis, and Compliance boundaries.
It strengthens Investment Education's grounded-output contract by requiring a bounded list of
supporting source IDs copied from approved retrieval metadata, an explicit uncertainty list,
plain-language explanations, and an English-or-Chinese response-language hint.
Application validation rejects citations that were not present in the accepted grounding.
