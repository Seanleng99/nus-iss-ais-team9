# Prompt Set v2

Status: active. This version adds grounded Investment Education RAG while preserving the
existing router, Spending, Budget, Goal Strategy, synthesis, and Compliance response schemas.

Investment Education must use only approved, sanitized retrieved contexts and must surface an
explicit evidence gap when retrieval is insufficient. Synthesis retains approved source metadata,
and Risk and Compliance receives the same education evidence for independent validation.

Prompt changes require updated evaluation evidence and a new version when behavior or policy
meaning changes.
